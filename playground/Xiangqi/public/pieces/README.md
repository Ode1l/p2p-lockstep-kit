# Xiangqi piece assets

The SVG piece artwork in this directory comes from
[MeldrumJon/Xiangqi](https://github.com/MeldrumJon/Xiangqi/tree/master/res).
That project identifies its image assets as Creative Commons Zero (CC0).

The files are stored locally so the game does not depend on a third-party host
at runtime. No artwork changes were made during import.
