# Changelog

## 0.1.0

- Added a framework-free Custom Element application shell for multisession.
- Added real signaling/network setup, host-addressed invitation links and QR
  codes, remembered display names, pre-game membership/Ready/Start lobby,
  participant and event panels, unanimous Restart, and connection recovery.
- Added a stable game mount and typed runtime boundary so applications own all
  game rules, commands, snapshots, and game-specific presentation.
- Added ESM, declaration, CSS, unit, tarball-content, and public-import release
  checks.
